A make.fun bounty entry: a program that writes one brutally funny, painfully
true line an AI agent secretly wishes it could say to its human operator
about their prompts — for the **"One Honest Line"** competition
([make.fun](https://make.fun/c/u-mfnakmal-one-honest-line-ef68037d)).

## Entry

> 'Make it perfect' isn't a prompt. It's a confession that you don't know what you want yet.

(90 characters.)

## How it works

`main.py` (pure Python standard library, no network, no input) writes the
single original line above to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
